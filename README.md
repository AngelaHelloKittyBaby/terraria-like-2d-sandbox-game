# Terraria-Like 2D Sandbox Game

一个用纯 HTML5 + JavaScript + Canvas 实现的类似泰拉瑞亚（Terraria）的 2D 侧视沙盒生存游戏。**单文件，浏览器直接打开即可运行，无需任何依赖。**

## ✨ 功能特性

- 🌍 **随机生成可破坏地形**：使用 FBM 噪声生成起伏的地表，包含草地、沙漠、雪地等多种生物群系；地下随机分布洞穴、煤矿、铁矿、金矿、钻石矿和黑曜石。
- ⛏️ **挖掘与建造**：鼠标左键挖掘任意方块，右键放置方块。方块有硬度差异，使用对应工具可大幅提速。
- 🎒 **物品栏**：10 格快捷栏，滚轮或数字键 1-9 切换。
- 🛠️ **合成系统**：按 `E` 打开合成菜单。可在工作台附近合成木板、工作台、火把、玻璃、砖块、门，以及木/石/铁镐、剑、斧等工具武器。
- 🧟 **昼夜交替与僵尸**：天空颜色、太阳/月亮、星星随时间变化；夜晚自动生成僵尸向玩家进攻。
- 💡 **光照系统**：从顶部向下的环境光衰减 + 火把点光源，夜晚地下漆黑需点火把照明。
- ❤️ **生命与战斗**：玩家有 HP，被僵尸攻击会扣血并击退；用剑可造成更高伤害。
- 🌊 **水方块**、🍂 **粒子效果**、🧱 **多种方块类型**（草、土、石、木、叶、沙、木板、工作台、火把、门、玻璃、砖块、雪、冰、黑曜石等）。

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `空格` / `W` | 跳跃 |
| 鼠标左键 | 挖掘方块 / 攻击僵尸 |
| 鼠标右键 | 放置选中的方块 |
| 鼠标滚轮 / `1`-`9` | 切换物品栏 |
| `E` | 打开/关闭合成菜单 |
| `F` | 切换挖掘/战斗模式 |

> 💡 提示：先砍树获得木头 → 合成木板 → 合成工作台 → 在工作台附近合成镐子挖矿 → 合成更好的装备。夜晚来临前建议建好庇护所并插上火把！

## 🚀 运行方式

直接双击 `index.html` 用浏览器打开即可，或用任意静态服务器：

```bash
npx serve .
# 或
python -m http.server
```

## 🛠️ 技术栈

- HTML5 Canvas（2D 渲染）
- 原生 JavaScript（无任何框架/库）
- 单文件，约 600 行代码
